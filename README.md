\# Простий калькулятор



Консольний калькулятор для базових арифметичних операцій на Python, створений у межах навчального проєкту.



\## Функціональність



\* Додавання двох чисел

\* Віднімання двох чисел

\* Множення двох чисел

\* Ділення двох чисел з перевіркою ділення на нуль

\* Піднесення до степеня та обчислення остачі від ділення
